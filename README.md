# COMPSCI 589 – Machine Learning

Homework projects completed as part of COMPSCI 589 – Machine Learning at the University of Massachusetts Amherst.

## Homework

- **Homework 1** – k-NN Algorithm and Decision Tree
- **Homework 2** – Multinomial Naïve Bayes
- **Homework 3** – Random Forest
- **Homework 4** – Neural Networks and Backpropagation

Each homework folder contains the Python/Jupyter Notebook code and the corresponding report.
